# Sinoise

Signal > noise.

Sinoise is a minimal Android reminder app focused on three goals for today, a persistent Not To Do list, independent interval or chosen-time reminders, quiet hours, and optional notification sound.

## Version history

- **v6 / 0.6.0** — Added independent Not To Do notifications with their own interval or chosen-time schedule.
- **v5 / 0.5.0** — Added About menu and current-version display.
- **v4** — Improved interval reminders with self-rescheduling alarms and distinct notifications.
- **v3** — Added sleep / quiet hours and optional notification sound.
- **v2** — Added exact chosen-time reminder support and exact-alarm permission flow.
- **v1** — Initial Sinoise MVP.
